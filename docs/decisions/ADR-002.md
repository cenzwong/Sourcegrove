# ADR-002: SwiftUI modular monolith

## Status
Accepted

## Context
The application needs to be organized logically and scale effectively, but distributing a desktop app with complex microservices is error-prone.

## Decision
Adopt a modular monolith architecture using local Swift packages to organize domains. The UI will be built natively with SwiftUI.

## Consequences
- Single distributable binary/app bundle.
- Clean boundaries between domain packages.
- Easy to manage via Swift Package Manager.
