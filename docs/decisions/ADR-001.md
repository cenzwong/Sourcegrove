# ADR-001: macOS 27 and Apple Silicon target

## Status
Accepted

## Context
The product needs to run locally on Apple hardware. We want to leverage the latest Native Apple frameworks to ensure optimal performance, native look and feel, and longevity without relying on backwards compatibility shims.

## Decision
Target macOS 27 as the minimum deployment target and compile exclusively for Apple Silicon (`arm64`). Use Xcode 27 toolchain and Swift 6 with strict concurrency.

## Consequences
- Requires modern Apple hardware and OS for users.
- Gives us full access to `NaturalLanguage`, `Vision`, `FoundationModels` improvements without fallback paths.
- Code can be simplified without needing `#available` checks for newer frameworks.
