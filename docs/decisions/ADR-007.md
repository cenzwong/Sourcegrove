# ADR-007: Native Rust interoperability boundary

## Status
Accepted

## Context
We need to use the embedded LanceDB engine for vector storage. LanceDB's core is written in Rust. Swift needs to interact with this engine safely and efficiently.

## Decision
Use a narrow manual C ABI bridge between Swift and Rust. Rust will expose a C API, which Swift will consume via a native wrapper (`VectorStore` API).

## Consequences
- Minimal interoperability surface area.
- Explicit memory ownership and management.
- Avoids the overhead and complexity of tools like UniFFI unless proven necessary.
- Prevents Rust types from bleeding into Swift application code.
